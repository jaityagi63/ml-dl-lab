### **Intro-to-pytorch**

[PyTorch](https://pytorch.org/) is an open-source machine learning framework.It provide a python-based-scientific Computation Package
- **A Replacement for numpy** and it uses GPUs for faster computation

### **Application:**
- **Data Manipulation:**  Process and transform multidimensional data structures
- **Algo Developement:**  can implement machine and deep learning Algo using automatic differentation
- **Model Prototyping** Rapidly develop and test neural network architectures

### **Advantage of pytorch:**
- **Research friendly Design:**
    1. pytorch uses **Dynamic Computation Graph** for model architecture 
    2. Extensive debugging capabilities with standard Python debugging tools

- **Performance Optimization:**
    1. Efficient GPU utilization through CUDA integration
    2. Optimized tensor operations for numerical computations
    3. Support for distributed training across multiple devices
